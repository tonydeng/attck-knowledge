## 技术描述

**内部代理**（T1090.001）是 **代理**（T1090）的一个具体变体，属于 **命令与控制** 阶段的攻击技术。

> 🔗 **打个比方**：就像通过中间人传递消息——攻击者使用代理服务器转发C2流量，隐藏真实服务器的位置。

### 具体怎么理解？

攻击者在被黑网络内部部署代理，转发内部流量

攻击者使用这种技术时，通常是在命令与控制阶段，想要达到特定的攻击目标。与父技术 T1090 相比，T1090.001 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要误以为C2只是'发心跳包'——现代C2基础设施堪比小型互联网公司。
3. **广泛适用**：可以在多种环境和系统中使用

## 真实攻击流程

### 典型场景

攻击者在 **命令与控制** 阶段使用 内部代理 技术，以下是典型的攻击步骤：

```mermaid
graph TD
    A["在内网部署代理服务器"] --> B["配置内网主机连接代理"]
    B --> C["所有C2流量经过内部代理"]
    C --> D["代理转发流量到外部C2"]
    D --> E["外部流量经代理分发到各主机"]
    style C fill:#ff6b6b,stroke:#333,stroke-width:2px
```

**步骤详解：**

1. **在内网部署代理服务器** - 在已控制的内网主机上安装代理软件（如Chisel、Socat）
2. **配置内网主机连接代理** - 设置其他受控主机将流量路由到内部代理节点
3. **所有C2流量经过内部代理** - 多台主机的C2通信统一汇聚到内部代理（关键步骤）
4. **代理转发流量到外部C2** - 内部代理将聚合的C2流量加密转发到外部C2服务器
5. **外部流量经代理分发到各主机** - 攻击者指令通过代理分发到对应的受控主机

## 攻击流程

```mermaid
graph LR
    A[在边缘主机部署内部代理服务监听端口] --> B[受控主机配置路由将C2流量指向代理]
    B --> C[多台主机C2流量汇聚到内部代理节点]
    C --> D[代理聚合流量加密转发到外部C2服务器]
    D --> E[外部指令经代理分发回各受控主机]
    
    style A fill:#4a90e2
    style E fill:#ff6b6b
```

**关键步骤说明：**

1. **在边缘主机部署内部代理服务监听端口**: 攻击者选择失陷的边缘主机（如DMZ Web服务器、运维跳板机、SCCM站点服务器）作为内部代理节点，部署Chisel/Socat/Frp/3proxy等代理工具，监听非标准端口（如8443/1080），伪装成业务进程名（如`svchost`、`MicrosoftEdgeUpdate`）以躲避EDR进程检测
2. **受控主机配置路由将C2流量指向代理**: 攻击者在其他失陷内网主机上设置代理客户端，修改C2 Beacon的出站配置或设置系统级代理（`netsh winhttp set proxy`、注册表`ProxyServer`项），将原本直接出站的C2流量改道经内部代理节点转发，规避直接出网触发防火墙告警
3. **多台主机C2流量汇聚到内部代理节点**: 多台受控主机的C2心跳、指令请求、数据回传流量统一汇聚到内部代理节点，代理节点通过流量聚合消除单台主机出网的"独占连接"特征，使外部C2看起来只与一台主机通信，混淆溯源
4. **代理聚合流量加密转发到外部C2服务器**: 内部代理节点将多台主机的C2流量复用为单条加密隧道（如TLS over 443、SSH隧道、QUIC）转发到外部真实C2服务器，对外只暴露代理节点IP，隐藏受控主机数量和真实身份，外部C2也只看到代理节点一个连接源
5. **外部指令经代理分发回各受控主机**: 外部C2服务器下发的指令通过加密隧道返回内部代理节点，代理节点根据内嵌会话ID将指令分发到对应受控主机的反向连接上，每台主机收到的指令看起来都来自内网代理节点（同段IP），而非外部C2，进一步降低内网检测告警概率

## 缓解措施

### 优先级1：关键措施

**限制攻击面**：减少暴露的服务和端口，降低被利用的风险

```bash
# 防火墙规则示例：只允许必要的出站连接
iptables -A OUTPUT -p tcp --dport 443 -j ACCEPT  # 允许HTTPS
iptables -A OUTPUT -p tcp --dport 80 -j ACCEPT   # 允许HTTP
iptables -A OUTPUT -p tcp -j DROP                 # 阻止其他TCP
```

### 优先级2：重要措施

**加强监控**：部署EDR和SIEM系统，实时监控异常行为

### 优先级3：建议措施

**安全意识培训**：教育员工识别相关攻击手法
