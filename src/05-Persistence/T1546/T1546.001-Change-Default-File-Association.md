## 技术描述

**更改默认文件关联**（T1546.001）是 **事件触发执行**（T1546）的一个具体变体，属于 **持久化** 阶段的攻击技术。

> 🔄 **打个比方**：就像在Windows的"事件日志"里设置了一个触发条件——攻击者利用事件订阅（Event Subscription）在特定事件发生时执行恶意代码。

### 具体怎么理解？

修改文件类型打开方式

攻击者使用这种技术时，通常是在持久化阶段，想要达到特定的攻击目标。与父技术 T1546 相比，T1546.001 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要以为持久化就是'写个启动项'那么简单——攻击者有50种以上维持访问的方法。
3. **广泛适用**：可以在多种环境和系统中使用

## 攻击流程

```
获取Windows访问权限 → 定位目标扩展名注册表项 → 修改shell\open\command → 用户双击该类型文件 → 恶意程序以用户权限执行
```

```mermaid
graph LR
    A["获取Windows访问权限"] --> B["定位扩展名注册表项"]
    B --> C["修改shell\open\command"]
    C --> D["用户双击.txt文件"]
    D --> E["触发恶意程序执行"]
```

**步骤详解：**

1. **获取Windows访问权限**
   - 通俗描述：攻击者获得目标系统的注册表修改权限
   - 技术细节：通过凭据窃取或漏洞利用获取用户权限；HKCU\Software\Classes 子树无需管理员即可写入，便于隐蔽持久化
   - 常用工具：Mimikatz、PsExec、Empire
2. **定位目标扩展名注册表项**
   - 通俗描述：查找常用文件扩展名对应的注册表项
   - 技术细节：定位 HKCU\Software\Classes\.txt、.docx、.pdf 等键；常用扩展名触发概率高（.txt/.jpg/.html）；HKCU 优先级高于 HKLM，可绕过组策略
   - 常用工具：reg query、regedit、PowerShell Get-ItemProperty
3. **修改shell\open\command**
   - 通俗描述：将文件类型的默认打开命令替换为恶意程序路径
   - 技术细节：写入 HKCU\Software\Classes\txtfile\shell\open\command 默认值为 "C:\malware\backdoor.exe" "%1"；%1 参数传递被双击文件路径，模拟正常打开行为
   - 常用工具：reg add、PowerShell Set-ItemProperty、regedit
4. **用户双击该类型文件**
   - 通俗描述：等待用户在日常工作中双击触发该类型文件
   - 技术细节：Explorer.exe 调用 ShellExecute → 读取注册表 command 键 → 执行恶意程序；可设置 Extended 子键需右键打开触发降低被检测概率
   - 常用工具：社会工程学钓鱼附件、用户日常操作
5. **触发恶意程序执行**
   - 通俗描述：恶意程序以用户权限自动运行，建立持久后门
   - 技术细节：后门程序可读取 %1 参数（被双击文件）并伪装打开原文件，用户无感知；后台建立C2回连或下载第二阶段Payload
   - 常用工具：Cobalt Strike、Empire、PowerShell reverse shell

### 主机层检测

**Windows事件ID**：
- 事件ID 4688：进程创建（监控可疑进程）
- 事件ID 4104：PowerShell执行（监控可疑脚本）

**Linux日志**：
- /var/log/auth.log：认证日志
- /var/log/syslog：系统日志

```bash

```

### 应用层检测

**用人话说：** 就像把你电脑上".txt"文件的"双击打开方式"从记事本偷偷改成了恶意程序——攻击者修改注册表`HKCR\.txt`或`HKCR\txtfile\shell\open\command`中的默认文件关联，当你双击一个看起来人畜无害的.txt文件时，实际启动的是恶意程序而不是记事本。这种技术特别阴险的地方在于：你每次打开文件都会触发，而且文件图标看起来完全正常。攻击者常用`assoc`和`ftype`命令或直接修改注册表来实现。
