## 技术描述

**代码签名证书**（T1588.003）是 **获取能力**（T1588）的一个具体变体，属于 **资源开发** 阶段的攻击技术。

> 💰 **打个比方**：就像租用别人的黑客工具——通过付费服务获得攻击能力，比自己开发更省事。

### 具体怎么理解？

购买或窃取代码签名证书，让恶意软件看起来合法

攻击者使用这种技术时，通常是在资源开发阶段，想要达到特定的攻击目标。与父技术 T1588 相比，T1588.003 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要以为资源开发只是'写恶意软件'——这是建立整个攻击作战体系的过程。
3. **广泛适用**：可以在多种环境和系统中使用

## 真实攻击流程

```mermaid
graph TD
    A["寻找代码签名证书卖家"]
    B["评估证书类型和有效期限"]
    C["与卖家谈判价格和支付方式"]
    D["购买证书及其私钥"]
    E["使用证书签名恶意软件"]
    A --> B
    B --> C
    C --> D
    D --> E
    style D fill:#ff6b6b,stroke:#333,stroke-width:2px
```

**步骤详解：**

1. **寻找证书卖家** - 攻击者在暗网论坛或Telegram频道寻找出售代码签名证书的卖家
2. **评估证书质量** - 检查证书的颁发机构、有效期限以及是否已被吊销
3. **谈判交易** - 与卖家协商价格，确定支付方式（通常比合法申请贵数倍）
4. **购买证书私钥** - 支付加密货币后获得证书文件及其私钥，这是获得签名能力的核心
5. **签名恶意软件** - 使用购买的证书对恶意软件进行数字签名，使其获得操作系统的信任

## 攻击流程

```
卖家渠道寻找 --> 证书质量评估 --> 私钥交易获取 --> 恶意软件签名
```

```mermaid
graph LR
    A["卖家渠道寻找"] --> B["证书质量评估"]
    B --> C["私钥交易获取"]
    C --> D["恶意软件签名"]
```

**步骤详解：**

1. **卖家渠道寻找** - 在暗网论坛或Telegram频道寻找出售被盗代码签名证书的卖家，定位有效证书来源 | 浏览Exploit.in、卡巴斯基威胁情报暗网监控、Telegram黑客频道 | Telegram, Exploit.in, 暗网市场
2. **证书质量评估** - 检查证书颁发机构（DigiCert/Sectigo等）、有效期、是否已被吊销（CRL/OCSP状态） | 验证证书链完整性、确认证书未被Microsoft SmartScreen标记、评估目标系统信任度 | sigcheck, OpenSSL, certutil
3. **私钥交易获取** - 支付加密货币获得证书文件（PFX/P12）及其私钥，价格通常比合法申请贵数倍 | 通过PGP加密通信传输私钥文件、使用门罗币支付避免追踪 | Monero (XMR), PGP, PFX证书文件
4. **恶意软件签名** - 使用购买的证书对恶意软件进行数字签名，使其获得操作系统信任绕过SmartScreen和EDR检测 | 使用SignTool签名、伪造时间戳、批量签名多个载荷 | SignTool, osslsigncode, Time Stamping Server
