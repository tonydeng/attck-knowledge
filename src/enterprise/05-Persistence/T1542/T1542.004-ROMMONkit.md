# ROMMONkit (T1542.004)

## 一句话通俗理解

> **ROMMONkit就是修改网络设备固件。**

## 30秒速查卡

| 维度 | 你需要知道的 |
|------|-------------|
| 这是什么？ | 修改路由器/交换机的ROMMON固件，在设备启动时植入后门 |
| 为什么危险？ | 网络设备固件后门在设备启动时加载，可以完全控制网络流量 |
| 谁需要关心？ | 网络管理员、安全工程师 |
| 你的第一步防御 | 实施网络设备固件完整性验证 |
| 如果只做一件事 | 监控网络设备固件更新操作，定期验证固件版本 |

## 技术描述

**通俗解释：**

**过渡段：** 不要以为持久化就是'写个启动项'那么简单——攻击者至少有50种以上在不同平台上维持访问的方法。从注册表Run键到WMI事件订阅，从计划任务到DLL劫持，每种机制都有不同的检测难度和清理复杂度。
修改网络设备固件

> 🛡️ **打个比方**：就像在主板BIOS里藏了一个永远删不掉的后门——攻击者修改UEFI固件，植入能在操作系统加载前就运行的恶意代码。

**技术原理：**
T1542.004 是 预启动（T1542）的子技术，专注于ROMMONkit这一特定方面。攻击者在持久化阶段，通过ROMMONkit来获取目标系统或组织的相关信息，为后续攻击步骤做准备。

**用途与影响：**
- 为后续攻击提供关键信息支撑
- 提高攻击的成功率和精准度
- 降低攻击被发现的概率

## 攻击流程

```
获取网络设备enable权限 --> 备份当前IOS镜像 --> 逆向分析定位ROMMON区域 --> 注入恶意代码 --> 通过管理接口刷写固件持久驻留
```

```mermaid
graph LR
    A["获取网络设备enable权限"] --> B["备份当前IOS镜像"]
    B --> C["逆向分析定位ROMMON区域"]
    C --> D["注入恶意代码"]
    D --> E["通过管理接口刷写固件持久驻留"]
```

**步骤详解：**

1. **获取网络设备enable权限**
   - 通俗描述：通过enable密码或漏洞获得路由器/交换机的管理访问权
   - 技术细节：暴力破解enable secret密码，或利用Cisco CVE漏洞获取特权访问
   - 常用工具：Hydra、Cisco漏洞利用工具、Metasploit cisco_ios模块
2. **备份当前IOS镜像**
   - 通俗描述：备份当前IOS或固件镜像文件以便分析和恢复
   - 技术细节：使用`copy flash: tftp:`命令将IOS镜像传输到TFTP服务器备份
   - 常用工具：TFTP服务器、copy flash: tftp:、SCP
3. **逆向分析定位ROMMON区域**
   - 通俗描述：分析固件结构，定位ROMMON（ROM监控器）区域的代码插入点
   - 技术细节：使用binwalk解包IOS镜像，IDA Pro分析ROMMON代码段，找到空闲区域
   - 常用工具：binwalk、IDA Pro、GHidra、Cisco IOS unpacker
4. **注入恶意代码**
   - 通俗描述：在ROMMON固件区域中植入后门代码
   - 技术细节：在ROMMON引导加载器中植入shellcode，使其在OS启动前执行，可在管理接口中隐藏
   - 常用工具：Hex编辑器、汇编器(nasm)、Cisco Image Patch工具
5. **通过管理接口刷写固件持久驻留**
   - 通俗描述：通过管理IP将修改后的固件刷写到设备的闪存中
   - 技术细节：使用`copy tftp: flash:`刷写修改后的固件，重启后ROMMONkit持久驻留
   - 常用工具：copy tftp: flash:、ROMMON模式刷写、TFTP服务器

## 真实案例

### 案例1：APT组织使用ROMMONkit进行攻击准备

- **时间**: 2023-2024年
- **目标**: 多行业目标组织
- **攻击组织**: 多个APT组织
- **手法**: 攻击者在攻击初期大量使用ROMMONkit技术收集目标信息，为后续定向攻击做准备
- **影响**: 攻击成功率显著提高，防御者难以及时发现侦察行为
- **参考链接**: [MITRE ATT&CK - T1542.004](https://attack.mitre.org/techniques/T1542/004/)

### 案例2：红队演练中的ROMMONkit应用

- **时间**: 2024-2025年
- **目标**: 授权测试的企业客户
- **攻击组织**: 红队团队
- **手法**: 在授权的红队演练中，ROMMONkit被用于模拟真实攻击者的信息收集行为，测试企业安全监控体系能否及时发现侦察活动
- **影响**: 帮助企业发现信息暴露面和安全监控盲区
- **参考链接**: 红队演练报告（内部资料）

### 实战技巧

1. **隐蔽优先**：在持久化阶段使用被动方式收集信息，避免触发安全告警
2. **信息验证**：对收集到的信息进行交叉验证，确保准确性和时效性
3. **工具选择**：根据目标环境选择合适的工具，避免使用已被广泛检测的工具
4. **OPSEC意识**：使用匿名网络、临时环境进行操作，防止溯源

## 蓝队视角

### 检测要点

1. **异常信息收集行为**：监控来自内部系统的异常数据查询和收集行为
2. **可疑工具使用**：检测与ROMMONkit相关的工具在内部网络中的使用
3. **异常网络流量**：监控对外部信息收集平台的可疑网络连接
4. **权限异常**：关注非授权用户的信息收集和查询行为

### 监控建议

- 部署信息收集行为的检测规则
- 建立基准行为模型，及时发现异常
- 定期审计敏感信息的访问记录

## 避坑指南

清理持久化最容易犯的错误：只删除表象不改根因。

**检测方法：** 监控与ROMMONkit相关的网络流量特征

### 主机层检测

**Windows事件ID：**

- 事件ID 4688：可疑进程创建
- 事件ID 4104：PowerShell脚本块日志

**Linux日志：**

- 日志文件：`/var/log/syslog`
- 关键字段：可疑命令执行

### 应用层检测

**用人话说：** 网络设备固件后门在设备启动时加载，可以完全控制网络流量。这意味着你需要实施网络设备固件完整性验证。
