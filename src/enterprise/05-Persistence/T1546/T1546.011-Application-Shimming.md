## 技术描述

**应用程序兼容性垫片**（T1546.011）是 **事件触发执行**（T1546）的一个具体变体，属于 **持久化** 阶段的攻击技术。

> 📂 **打个比方**：就像在Windows的文件资源管理器里加了一个隐藏的插件——攻击者利用文件管理器扩展（File Manager Extension）在文件操作时执行恶意代码。

### 具体怎么理解？

使用sdbinst安装垫片

攻击者使用这种技术时，通常是在持久化阶段，想要达到特定的攻击目标。与父技术 T1546 相比，T1546.011 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要以为持久化就是'写个启动项'那么简单——攻击者有50种以上维持访问的方法。
3. **广泛适用**：可以在多种环境和系统中使用

## 攻击流程

```
获取Windows管理员权限 → 创建恶意.sdb垫片数据库 → sdbinst安装 → 配置目标应用修复 → 目标程序启动加载垫片执行
```

```mermaid
graph LR
    A["获取管理员权限"] --> B["创建恶意.sdb"]
    B --> C["sdbinst安装"]
    C --> D["配置目标应用修复"]
    D --> E["目标程序启动触发垫片"]
```

**步骤详解：**

1. **获取Windows管理员权限**
   - 通俗描述：安装Shim数据库需要管理员权限
   - 技术细节：通过凭据窃取、漏洞利用或已有管理员账号；需对注册表 HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\AppCompatFlags 具备写权限
   - 常用工具：Mimikatz、PsExec、UACME
2. **创建恶意.sdb垫片数据库**
   - 通俗描述：使用兼容性工具创建包含恶意修复的Shim数据库文件
   - 技术细节：使用 Application Compatibility Toolkit (ACT) 或 SHIMdb 工具创建 .sdb 文件；包含目标EXE路径、修复类型（InjectDLL、RedirectEXE、DisableNXShowUI）；InjectDLL 修复可指定恶意DLL路径
   - 常用工具：Application Compatibility Toolkit、sdb2xml、Custom SDB Builder
3. **sdbinst安装**
   - 通俗描述：使用sdbinst.exe将垫片数据库安装到系统
   - 技术细节：执行 `sdbinst.exe -q malicious.sdb`（-q 静默安装）；写入注册表 HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\InstalledSDB；可在控制面板"已安装的程序"中看到条目
   - 常用工具：sdbinst.exe、PowerShell、wmic
4. **配置目标应用修复**
   - 通俗描述：在.sdb中指定被垫片劫持的目标可执行文件
   - 技术细节：目标程序选择高频系统工具（notepad.exe、calc.exe、sethc.exe）；匹配规则可用文件名、版本信息、SHA256；InjectDLL 修复会在目标进程启动时注入指定DLL
   - 常用工具：ACT、SDB Explorer、文本编辑器
5. **目标程序启动加载垫片**
   - 通俗描述：用户或系统启动目标程序时，垫片中的恶意代码被执行
   - 技术细节：应用程序兼容性引擎（PCALua.exe）检查目标程序 → 匹配.sdb修复 → 应用InjectDLL注入恶意DLL；DLL在目标进程地址空间执行；以目标进程权限运行
   - 常用工具：系统自动加载、LoadLibrary

### 应用层检测

**用人话说：** 就像给一个程序戴上"美颜滤镜"——Windows应用程序兼容性垫片（Shim）是官方提供的兼容性修复机制，允许在不修改程序本身的情况下改变其行为。攻击者使用`sdbinst`工具安装恶意垫片数据库（.sdb文件），垫片可以挂钩API函数、重定向文件路径、注入DLL。比如"RedirectShim"可以将程序的某个API调用重定向到恶意代码。因为垫片是Windows官方认可的技术，杀毒软件很难区分正常垫片和恶意垫片。NSA的"永恒之蓝"漏洞利用中就使用了垫片技术。
