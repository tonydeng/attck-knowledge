## 技术描述

**协议模仿**（T1001.003）是 **数据混淆**（T1001）的一个具体变体，属于 **命令与控制** 阶段的攻击技术。

> 📊 **打个比方**：就像把情报伪装成普通的收发记录——攻击者通过模拟正常的通信协议行为来隐藏C2流量。

### 具体怎么理解？

让C2流量装成 HTTP API、WebSocket 等合法协议的样子

攻击者使用这种技术时，通常是在命令与控制阶段，想要达到特定的攻击目标。与父技术 T1001 相比，T1001.003 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要误以为C2只是'发心跳包'——现代C2基础设施堪比小型互联网公司。
3. **广泛适用**：可以在多种环境和系统中使用

## 真实攻击流程

### 典型场景

攻击者在 **命令与控制** 阶段使用 协议模仿 技术，以下是典型的攻击步骤：

```mermaid
graph TD
    A["分析目标网络合法协议特征"] --> B["构建模仿合法协议的C2模块"]
    B --> C["C2流量伪装为HTTP/WebSocket"]
    C --> D["安全设备将其识别为正常流量"]
    D --> E["隐蔽传输C2指令和数据"]
    style C fill:#ff6b6b,stroke:#333,stroke-width:2px
```

**步骤详解：**

1. **分析目标网络合法协议特征** - 研究目标网络中常见的协议类型和流量模式
2. **构建模仿合法协议的C2模块** - 开发能够模拟HTTP API、WebSocket等合法协议行为的C2组件
3. **C2流量伪装为HTTP/WebSocket** - 将C2通信伪装为正常的API调用或WebSocket连接（关键步骤）
4. **安全设备将其识别为正常流量** - 由于协议特征匹配，DPI设备将流量放行
5. **隐蔽传输C2指令和数据** - 在看似合法的协议连接中隐蔽传输攻击指令

## 攻击流程

```
分析目标网络合法协议 --> 构建协议模仿C2模块 --> 伪装合法会话行为传输指令 --> 规避深度包检测
```

```mermaid
graph LR
    A["分析目标网络合法协议"] --> B["构建协议模仿C2模块"]
    B --> C["伪装合法会话行为传输指令"]
    C --> D["规避深度包检测"]
```

**步骤详解：**

1. **分析目标网络合法协议**
   - 通俗描述：先"踩点"摸清目标公司网络里都跑哪些正常协议，挑一个最像的来模仿
   - 技术细节：通过流量嗅探（Wireshark/Zeek）统计目标出口流量中占比最高的协议（如HTTPS API调用、WebSocket长连接、gRPC），记录TLS指纹（JA3/JA4）、Header顺序、心跳间隔等行为基线
   - 常用工具：Wireshark、Zeek、mitmproxy、JA3指纹库

2. **构建协议模仿C2模块**
   - 通俗描述：照着正常协议的样子，做一个"高仿"的C2通信模块
   - 技术细节：基于开源协议栈实现C2收发逻辑，确保TLS握手ClientHello字段顺序、ALPN协商、HTTP/2 SETTINGS帧等与真实浏览器/客户端一致；使用Malleable C2 profile定义请求路径、Content-Type、响应体结构
   - 常用工具：Cobalt Strike Malleable C2、Mythic、自定义Go/Rust HTTP2客户端

3. **伪装合法会话行为传输指令**
   - 通俗描述：让C2流量表现得像正常浏览器在访问API，连请求节奏都一模一样
   - 技术细节：模拟真实用户会话模式——先GET首页获取Cookie，再POST表单，请求间隔服从正态分布；指令数据封装在JSON字段名（如 `user_id`、`session_token`）中，响应伪装成标准REST API JSON结构
   - 常用工具：Cobalt Strike、ShadowChain、自定义Python aiohttp客户端

4. **规避深度包检测**
   - 通俗描述：因为流量长得太像正常API调用，连DPI设备都认不出来，直接放行
   - 技术细节：通过TLS 1.3加密隐藏payload，配合域名前置（Domain Fronting）将SNI指向CDN域名而实际请求Host头指向C2；定期切换User-Agent、Referer等指纹避免基于行为基线的异常检测
   - 常用工具：Domain Fronting配置、Cloudflare/Akamai CDN、自定义TLS客户端

**限制攻击面**：减少暴露的服务和端口，降低被利用的风险

```bash
# 防火墙规则示例：只允许必要的出站连接
```
