## 技术描述

**隐写术**（T1001.002）是 **数据混淆**（T1001）的一个具体变体，属于 **命令与控制** 阶段的攻击技术。

> 📅 **打个比方**：就像在规定的日子才接头交换情报——攻击者按照预定的时间计划发送和接收C2指令，不规律性降低。

### 具体怎么理解？

把C2指令藏在图片、音频文件中，表面看是完全正常的文件

攻击者使用这种技术时，通常是在命令与控制阶段，想要达到特定的攻击目标。与父技术 T1001 相比，T1001.002 有自己独特的特点和使用场景。

### 为什么有效？

这种技术之所以有效，是因为：
1. **隐蔽性**：利用了正常系统功能或常见协议，不容易被发现
2. **技术门槛适中**：不需要特别高深的技术知识就能实施

**过渡段：** 不要误以为C2只是'发心跳包'——现代C2基础设施堪比小型互联网公司。
3. **广泛适用**：可以在多种环境和系统中使用

## 真实攻击流程

### 典型场景

攻击者在 **命令与控制** 阶段使用 隐写术 技术，以下是典型的攻击步骤：

```mermaid
graph TD
    A["准备图片/音频载体文件"] --> B["将C2指令嵌入文件像素/频谱"]
    B --> C["上传载有指令的文件到网站"]
    C --> D["木马下载并解析隐写内容"]
    D --> E["提取隐藏指令并执行"]
    style B fill:#ff6b6b,stroke:#333,stroke-width:2px
```

**步骤详解：**

1. **准备图片/音频载体文件** - 选择看似正常的图片（PNG/JPG）或音频文件作为载体
2. **将C2指令嵌入文件像素/频谱** - 使用LSB隐写等技术将指令数据嵌入文件的最低有效位（关键步骤）
3. **上传载有指令的文件到网站** - 将隐写后的文件上传到公共图床或攻击者控制的网站
4. **木马下载并解析隐写内容** - 恶意载荷下载文件并使用逆向算法提取隐藏数据
5. **提取隐藏指令并执行** - 从隐写数据中解码出C2指令并执行相应操作

## 攻击流程

```
准备载体媒体文件 --> 将指令编码嵌入载体 --> 上传载体到公开平台 --> 客户端下载并提取隐藏指令
```

```mermaid
graph LR
    A["准备载体媒体文件"] --> B["将指令编码嵌入载体"]
    B --> C["上传载体到公开平台"]
    C --> D["客户端下载并提取隐藏指令"]
```

**步骤详解：**

1. **准备载体媒体文件**
   - 通俗描述：挑一张看起来人畜无害的猫狗图片或流行音乐文件，作为藏情报的"外壳"
   - 技术细节：选择体积适中（>100KB）的PNG/BMP无损图片或WAV音频作为载体，避免JPEG有损压缩破坏隐写数据；优先使用社交媒体常见的萌图、表情包降低怀疑
   - 常用工具：steghide、OpenStego、Python PIL库

2. **将指令编码嵌入载体**
   - 通俗描述：把C2指令"种"进图片像素的最末位，肉眼完全看不出变化
   - 技术细节：使用LSB（最低有效位）算法将指令字节写入图片RGB通道的最低位，或对音频采用频域隐写（DCT系数修改）；指令可先用AES加密再嵌入，提取时需密钥解密
   - 常用工具：steghide、LSB-Steganography、Python stepic

3. **上传载体到公开平台**
   - 通俗描述：把"藏着情报"的图片传到Twitter、Imgur等公开网站，混在海量正常图片里
   - 技术细节：通过API或手动方式将隐写文件上传至公共图床、社交媒体、博客评论区等高流量平台；载体URL作为C2"死信箱"，客户端按预定义关键词或账号定期检索
   - 常用工具：Twitter API、Imgur API、Telegram Bot API

4. **客户端下载并提取隐藏指令**
   - 通俗描述：失陷主机上的木马定期去这些网站"看图"，用相同算法把情报抠出来
   - 技术细节：C2客户端按预定周期下载载体文件，调用与攻击者一致的提取算法还原隐写数据，解密后获得真实C2指令（如反弹shell地址、横向移动任务）；提取完成后删除载体文件灭迹
   - 常用工具：自定义steg提取模块、steghide extract、Python stepic.decode

**限制攻击面**：减少暴露的服务和端口，降低被利用的风险

```bash
# 防火墙规则示例：只允许必要的出站连接
```
